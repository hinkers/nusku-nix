# nusku-nix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Nusku desktop (nusku-arch) on NixOS as a flake where each machine's installer answers are committed, so any machine rebuilds identically and rolls back from the boot menu.

**Architecture:** A flake whose `nixosConfigurations` are generated from `hosts/<name>/settings.json` (+ that host's `hardware-configuration.nix`). A `nusku.*` option module carries the answers; NixOS modules do the system, Home Manager modules link nusku-arch's dotfiles and render the accent-dependent ones from a Nix palette; catppuccin/nix themes the apps it covers. A Bash installer (nusku-arch's archinstall-style TUI) writes the host files and runs `nixos-rebuild`.

**Tech Stack:** Nix flakes, NixOS unstable, Home Manager, catppuccin/nix, Hyprland 0.57 (Lua config), Bash + gum + jq, bats, Docker `nixos/nix` for evaluation tests, Hyper-V.

**Spec:** `docs/superpowers/specs/2026-10-31-nusku-nix-design.md`. **Behaviour reference:** nusku-arch at `C:\Users\hinke\Repos\Nusku` (GitHub `hinkers/nusku-arch`) — tasks say "port X from nusku-arch"; read the named files there and reproduce the look and behaviour.

## Global Constraints

- Inputs: `nixpkgs` = `github:NixOS/nixpkgs/nixos-unstable`; `home-manager` (master, follows nixpkgs); `catppuccin` = `github:catppuccin/nix` (follows nixpkgs). Pinned by committed `flake.lock`.
- Catppuccin **Mocha**; accent one of the 14: rosewater flamingo pink mauve red maroon peach yellow green teal sky sapphire blue lavender.
- Nothing installs software outside Nix: Mason off, no ArtCraft Launcher, no Flatpak, no AUR.
- ArtCraft group = nixpkgs' 9: photocraft vectorcraft lightcraft pdfcraft wordcraft soundcraft deckcraft cadcraft gridcraft.
- Dropped: Zen Browser, UFW, Flatpak, AUR helper, multilib, the four ArtCraft apps nixpkgs lacks.
- Chromium instead of Chrome; Firefox, Chromium and Obsidian themed via catppuccin/nix.
- Renames: libreoffice-fresh → `libreoffice`; kdenlive → `kdePackages.kdenlive`; godot → `godot_4`.
- Unfree allowed (`nixpkgs.config.allowUnfree = true`).
- Written from scratch; nothing copied from Omarchy. Porting nusku-arch's own files is expected.
- `.gitattributes`: `* text=auto eol=lf` (the owner works on Windows; scripts must stay LF).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Test commands (Docker Desktop must be running on the Windows host):
  - `bash test/run-eval.sh [host]` — in `nixos/nix`, evaluates `.#checks.x86_64-linux` (every fixture host's `config.system.build.toplevel.drvPath` + named assertions). Evaluation only, no full builds.
  - `bash test/run-unit.sh [name]` — bats + shellcheck for the installer and scripts (image `nusku-nix-test`: bats, shellcheck, jq, gum, git).
  - VM: `powershell -NoProfile -ExecutionPolicy Bypass -File test\hyperv\Invoke-NuskuNixTest.ps1 [-Host vm-full]` (run from the PowerShell tool, not Git Bash).

## Review Focus

- A host file missing an optional key, or with an unknown app/lang id → evaluation fails with a message naming the key/id, not a Nix stack trace. (Task 1 assertion tests.)
- Reinstalling a known host on a machine whose disk UUIDs changed → the script must replace that host's `hardware-configuration.nix` from `/etc/nixos`, keep `settings.json`, and ask nothing. (Task 10 test.)
- Running the installer twice, or `--apps` with nothing changed → no duplicate host entries, no new git commit when settings are unchanged. (Task 10 test.)
- The user's own files (`~/.config/nusku/local.lua`, `local.zsh`, wallpaper choice) survive rebuilds and are never overwritten by Home Manager. (Task 4 eval test: these paths are not in `home.file`/`xdg.configFile`; activation creates them only if missing.)
- An NVIDIA hybrid laptop without detected bus IDs → evaluation fails with a clear message rather than a broken PRIME config. (Task 3 test.)

`settings.json` schema (Task 1 owns it; the installer writes it):

```json
{ "hostname": "laptop", "user": "nathan", "timezone": "Australia/Brisbane",
  "locale": "en_AU.UTF-8", "keymap": "us",
  "boot": { "loader": "systemd-boot" },            // or { "loader": "grub", "device": "/dev/sda" }
  "gpu": "hybrid-intel", "nvidia": "open",          // gpu: amd|intel|nvidia|hybrid-intel|hybrid-amd|vm ; nvidia: open|proprietary|null
  "prime": { "intelBusId": "PCI:0:2:0", "nvidiaBusId": "PCI:1:0:0" },   // hybrid only
  "panels": [ { "output": "eDP-1", "scale": 1.25 } ],
  "accent": "blue", "apps": ["firefox", "obsidian"], "langs": ["python"] }
```
